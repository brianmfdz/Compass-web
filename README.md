# A Web Compass

A real working compass that runs in the browser. Built with vanilla HTML, CSS and JavaScript. no libraries or frameworks.
Uses your device's magnetometer for live direction and GPS for coordinates.
> **Note:** Compass functionality requires a mobile device with a magnetometer.

## Live Demo
[View Live](https://brianmfdz.github.io/Compass-web/)

## How to Use
1. Open on your mobile browser
2. Allow motion and location permissions
3. Point your phone and navigate!

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Device Orientation API
- Geolocation API
